## Prinsip pekerjaan yang disepakati

1. **Audit awal satu kali atas seluruh soal** dalam paket: kemandirian pertanyaan, kecocokan stimulus, mutu variasi, kunci/opsi, pembahasan, dan kecocokan sumber Markdown dengan JSON operasional.
2. **Pertahankan soal yang lulus audit awal.** Jangan audit ulang nomor tersebut.
3. **Perbaiki hanya nomor yang bermasalah**, lalu sinkronkan JSON operasional terhadap sumber Markdown yang sudah lebih benar dan sesuai asetnya. Pertahankan ID dan kuantitas.
4. **Audit ulang hanya nomor revisi**. Bila masih salah, revisi dan cek ulang nomor tersebut saja sampai lulus.
5. Pengaman struktur jumlah, keunikan ID, ketersediaan aset dan kesesuaian manifest bukan audit isi ulang nomor yang sudah lolos.

## Temuan utama

Ditemukan **ketertinggalan konversi/sinkronisasi JSON**, bukan sekadar masalah kosmetik pertanyaan:

- **Inggris Unit 8:** 50 soal JSON lama mengenai makanan/minuman, tetapi Markdown yang telah disusun dan SVG yang tersimpan menguji **aktivitas di sekolah**, kata kerja `study / teach / eat / drink / buy / read / write / play / pray`.
- **Inggris Unit 9:** 50 soal JSON lama menguji banyak kata sifat yang berlainan, sedangkan Markdown+SVG menggunakan **clean, dirty, big, large, small, narrow, wide** dan kalimat lengkap untuk menggambarkan kondisi ruangan.
- **Inggris Unit 10:** 50 soal JSON lama berfokus pada angka 10–20, sedangkan Markdown dan SVG yang telah tersedia menguji **bilangan 21–50**, angka pada kartu, jumlah benda, serta pengelompokan puluhan dan satuan.
- **PJOK Bab 1:** 35 soal teks sudah **sama dengan Markdown dan tidak perlu disentuh**. Namun, 10 soal bergambar dalam JSON berisi pertanyaan/kunci lain daripada gambar dan Markdown sumber yang lebih lengkap.
- **PJOK Bab 2:** 35 soal teks dan 10 soal bergambar JSON lama repetitif/berbeda dari Markdown hasil penyusunan yang sudah lebih bervariasi; seluruh 45 soal operasional perlu diselaraskan.

Untuk lima kelompok ini, berkas **SVG aktual** mendukung konten Markdown, bukan versi JSON lama. Sumber Markdown sudah memiliki 4 opsi berbeda, tepat satu jawaban sesuai opsi, pembahasan, ID yang benar, dan kuantitas sesuai target. Karena itulah versi Markdown yang lebih matang dijadikan sumber untuk memulihkan JSON operasional.

## Materi MOD-01/MOD-02 — perbaikan tambahan yang diperlukan

Audit awal mengungkap bahwa **6 modul operasional** Inggris Unit 8–10 juga tertinggal dari materi Markdown. Contoh: modul JSON Unit 10 lama menyampaikan angka 10–20 tetapi bank soal yang benar membahas 21–50. Selain itu, beberapa modul lama memasang gambar dengan judul yang tidak cocok dengan SVG baru.

Karena ketidaksesuaian materi akan langsung merugikan pembelajaran sebelum siswa mengerjakan kuis, **6 modul JSON diselaraskan** dengan Markdown materi masing-masing:

- `eng-b08-materi.json`: MOD-01 **Activities at school**; MOD-02 **Match activities and places**.
- `eng-b09-materi.json`: MOD-01 **Room conditions**; MOD-02 **Describe two rooms**.
- `eng-b10-materi.json`: MOD-01 **Numbers 21–50**; MOD-02 **Counting school objects**.

Semua 6 ID dan versi MOD dipertahankan. **Isi modul cocok dengan sumber Markdown** setelah URL media relatif diubah menjadi URL GitHub Raw yang dapat digunakan frontend; **6 referensi SVG materi** diverifikasi tersimpan.

**Catatan PJOK:** Materi Bab 1–2 tersedia dalam berkas Markdown, tetapi belum ada `pjk-b01-materi.json` / `pjk-b02-materi.json` di repository. Konfigurasi kelas juga masih memasang `materialsAvailable:false` pada PJOK. **Pembuatan modul JSON dan aktivasi materi PJOK adalah pekerjaan integrasi terpisah**, bukan kegagalan bank soal pada pengerjaan ini; tidak diaktifkan tanpa konversi dan pengujian loader.

## Audit ulang terfokus — lulus

Audit ulang dilakukan dengan **mengambil kembali file yang sudah di-commit dari `main`**, lalu membandingkan tiap nomor revisi dengan Markdown yang terkait dan baseline sebelum perubahan:

- **Inggris Unit 8:** 35 teks + 10 gambar + 5 listening = **50/50 PASS**.
- **Inggris Unit 9:** 35 teks + 10 gambar + 5 listening = **50/50 PASS**.
- **Inggris Unit 10:** 35 teks + 10 gambar + 5 listening = **50/50 PASS**.
- **PJOK Bab 1:** 10 soal bergambar 036–045 = **10/10 PASS**.
- **PJOK Bab 2:** 35 teks + 10 bergambar = **45/45 PASS**.

Seluruh **205 ID revisi** memiliki 4 opsi unik, tepat satu kunci yang cocok, pembahasan tidak kosong, dan **0 perbedaan JSON–Markdown** pada pertanyaan, opsi beserta urutannya, jawaban, pembahasan, metadata gambar, maupun TTS yang berlaku. Jumlah soal dan ID tetap 240 unik. Semua gambar terkait tersedia di repositori. Perubahan media tidak menambah file gambar dan tidak menghapus ID.

Pada enam modul Inggris yang diperbarui, setiap judul, versi, isi materi, dan URL gambar direkonstruksi dari sumber Markdown serta diperiksa ulang setelah commit: **6/6 modul cocok**.

**Batas verifikasi:** Pemeriksaan konten/struktur dan sumber SVG dilakukan dari GitHub. Ini **bukan** pengujian semua SVG secara visual di HP, pembacaan layar dengan accessibility service, menjalankan loader JSON produksi, maupun uji pengucapan TTS pada Android WebView. Semua itu tetap memerlukan tes pada aplikasi nyata.
