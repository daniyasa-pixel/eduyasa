# Perbaikan konteks soal Bahasa Indonesia Kelas 6 Bab 2

Status: 18 soal diperbaiki; JSON siap digunakan aplikasi.

- Cakupan: bank `bin/bin-b02.json`, 50 soal. Pemeriksaan terfokus pada kemandirian konteks, bukan audit akademik menyeluruh mata pelajaran.
- ID terdampak (awalan `BIN-B02-M01-`): 001–006, 008, 020, 021, 023, 025–031, 043.
- Setiap soal terdampak kini memuat teks latihan dan pertanyaan dalam properti `text` yang sama. Tidak bergantung pada versi materi, urutan kuis, atau soal lain.
- Teks ditulis ulang sebagai latihan mandiri; bukan kutipan verbatim dari cerita terbitan. Ringkasan legenda tetap dinyatakan sebagai legenda, bukan fakta ilmiah.
- Pembahasan diperbarui agar mengacu pada bukti dalam teks masing-masing.
- ID, urutan bank, empat opsi, dan kunci jawaban dipertahankan. Sebanyak 32 soal lainnya tidak diubah. Tidak memerlukan aset gambar baru.
- Sumber Markdown untuk 18 revisi: `bin/bin-b02-revisi-mandiri.md`. JSON tetap satu bank operasional yang sama.

## Verifikasi

- JSON valid; 50 soal dan 50 ID unik.
- Seluruh soal memiliki empat opsi berbeda dan kunci identik dengan satu opsi.
- Perbandingan dengan sumber sebelum revisi memastikan tepat 18 soal berubah, hanya pada teks dan pembahasan.
- Pemeriksaan isi 18 soal: stimulus disertakan, pertanyaan dapat dijawab dari stimulus, dan satu opsi cocok dengan informasi yang diberikan.
- Normalisasi memakai `HTML/quiz-bank.js` dan 100 pengambilan acak: masing-masing 20 soal unik; teks tetap utuh; kunci tetap tersedia sesudah pengacakan opsi.
- Renderer aplikasi memakai `textContent` dan CSS `white-space: pre-wrap`, sehingga paragraf stimulus termasuk dalam teks yang ditampilkan.
- Tidak menjalankan uji browser penuh atau memverifikasi cache pada perangkat pengguna. Aplikasi membaca JSON pada path lama; sesi kuis yang sudah dimulai perlu dimulai ulang untuk mengambil data baru.
